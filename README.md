## 🚀 Como Usar e Executar Localmente

**1.** Faça o clone deste repositório para a sua máquina:
```bash
git clone [https://github.com/zack-rodrigues/Estudo.Py.BR.git](https://github.com/zack-rodrigues/Estudo.Py.BR.git)
```

**2.** Navegue pelos diretórios e execute o exercício desejado:
```bash
cd "Estrutura Sequencial"
python alo_mundo.py
```

- 🔍 **Navegue** pelos diretórios por tópico.
- 🧠 **Pratique** resolvendo os desafios antes de olhar o código.
- 🔄 **Compare** suas soluções com as respostas sugeridas nos arquivos `.py`.

<br>

## 🛠️ Ferramentas Recomendadas

- ✅ **Interpretador:** [Python 3.10+](https://www.python.org/downloads/)
- ✅ **Editores de Código:** [VS Code](https://code.visualstudio.com/) ou IDEs profissionais da família JetBrains.
- ✅ **Testes Rápidos:** [Jupyter Notebook](https://jupyter.org/) para experimentação em blocos.
- ✅ **Análise de Dados:** Para os exercícios avançados que geram relatórios, recomendo o uso do **LibreOffice Calc** para visualização, limpeza e formatação rápida das saídas estruturadas.
