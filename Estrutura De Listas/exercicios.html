16. Distribuição Salarial

Calcule o salário de vendedores (base $200 + 9% de comissão das vendas). Usando uma lista de contadores, identifique quantos receberam salários nas faixas $200-299, $300-399, etc, até a faixa de $1000 ou mais.

while True:
    vendas = float(input("Digite o total de vendas brutas (ou 0 para encerrar): $ "))
    if vendas == 0:
        break
        
    salario = 200 + (vendas * 0.09)
    print(f"Salário final: $ {salario:.2f}\n")
    
    # Lógica matemática para achar a posição (índice) na lista
    # Ex: 250 // 100 = 2. 2 - 2 = Índice 0
    indice = int(salario // 100) - 2
    
    # Se estourar a faixa limite (salário >= 1000), fixa no último índice
    if indice > 8:
        indice = 8
        
    contadores[indice] += 1

print("\n--- Distribuição Salarial ---")
for i in range(8):
    print(f"$ {i * 100 + 200} - $ {i * 100 + 299}: {contadores[i]} vendedor(es)")
print(f"$ 1000 em diante: {contadores[8]} vendedor(es)")

23. Monitoramento de Disco (Versão em Memória)

Levante o espaço em disco usado pelos usuários (informado em bytes). Converta os dados para Megabytes, calcule o percentual de uso de cada um sobre o total da empresa, e gere o relatório gerencial.

def bytes_para_mb(bytes_size):
    return bytes_size / (1024 * 1024)

usuarios = []
espacos_bytes = []

print("Digite 'sair' no nome para finalizar.")
while True:
    nome = input("Nome do usuário: ")
    if nome.lower() == "sair": break
    espaco = int(input(f"Espaço usado por {nome} (em bytes): "))
    
    usuarios.append(nome)
    espacos_bytes.append(espaco)

if len(usuarios) > 0:
    espaco_total_mb = bytes_para_mb(sum(espacos_bytes))
    
    print("\nACME Inc.           Uso do espaço em disco pelos usuários")
    print("-" * 65)
    print("Nr.  Usuário        Espaço utilizado     % do uso")
    
    for i in range(len(usuarios)):
        espaco_mb = bytes_para_mb(espacos_bytes[i])
        perc = (espaco_mb / espaco_total_mb) * 100
        print(f"{i+1:<4} {usuarios[i]:<14} {espaco_mb:>7.2f} MB {perc:>15.2f}%")
        
    print("-" * 65)
    print(f"Espaço total ocupado: {espaco_total_mb:.2f} MB")
    print(f"Espaço médio ocupado: {(espaco_total_mb / len(usuarios)):.2f} MB")
