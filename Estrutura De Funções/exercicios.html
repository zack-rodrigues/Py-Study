2. Triângulo Numérico

Crie uma função que receba um valor `n` e construa o seguinte padrão numérico em forma de triângulo retângulo:

1 1 2 1 2 3 ..... 1 2 3 ... n
def imprimir_triangulo(n):
    for i in range(1, n + 1):
        # Usamos List Comprehension para gerar os números de 1 até a linha atual 'i'
        linha = [str(numero) for numero in range(1, i + 1)]
        # O join agrupa a lista com espaços
        print(" ".join(linha))

6. Conversão de Horário (24h para 12h)

Faça um programa que converta um horário do formato 24 horas para 12 horas (ex: 14:25 vira 02:25 P.M.). Você deve criar uma função para a conversão e outra função apenas para a exibição na tela.

def converter_hora(hora, minuto):
    periodo = "A.M."
    
    if hora == 0:
        hora_convertida = 12
    elif hora == 12:
        hora_convertida = 12
        periodo = "P.M."
    elif hora > 12:
        hora_convertida = hora - 12
        periodo = "P.M."
    else:
        hora_convertida = hora
        
    return hora_convertida, minuto, periodo

def exibir_hora(h, m, p):
    # O :02d garante que os minutos tenham 2 casas (ex: 05 ao invés de 5)
    print(f"Horário convertido: {h:02d}:{m:02d} {p}\n")

while True:

    if h == -1:
        break
    m = int(input("Digite os minutos (0 a 59): "))
    
    h_conv, m_conv, periodo = converter_hora(h, m)
    exibir_hora(h_conv, m_conv, periodo)

7. Cálculo de Pagamento (Multas e Juros)

Crie a função valorPagamento. Se o dia de atraso for zero, retorne o valor normal. Se houver atraso, cobre 3% de multa fixa + 0,1% de juros por dia de atraso. O programa principal deve pedir as prestações em loop até o usuário digitar 0, imprimindo o relatório final no encerramento.

def valorPagamento(valor, dias_atraso):
    if dias_atraso == 0:
        return valor
    else:
        multa = valor * 0.03
        juros = valor * (0.001 * dias_atraso)
        return valor + multa + juros

total_arrecadado = 0
qtd_prestacoes = 0

while True:
    valor_prestacao = float(input("\nValor da prestação (0 para sair): R$ "))
    if valor_prestacao == 0:
        break
        
    atraso = int(input("Dias em atraso: "))
    
    # Chama a função
    valor_pago = valorPagamento(valor_prestacao, atraso)
    print(f"Valor a ser pago: R$ {valor_pago:.2f}")
    
    # Acumuladores para o relatório final
    total_arrecadado += valor_pago
    qtd_prestacoes += 1

print("\n--- Relatório do Dia ---")
print(f"Prestações pagas: {qtd_prestacoes}")
print(f"Total arrecadado: R$ {total_arrecadado:.2f}")

9. Reverso do Número

Faça uma função que retorne o reverso de um número inteiro informado. Exemplo: Se o usuário enviar 127, a função retorna 721.

def reverso_numero(numero):
    # Removemos o sinal, invertemos com o slicing [::-1]
    num_invertido = str(abs(numero))[::-1]
    
    # Devolvemos o sinal de menos se for negativo e retornamos como inteiro
    if numero < 0:
        return int("-" + num_invertido)
    
    return int(num_invertido)

num = int(input("Digite um número: "))
print(f"O reverso de {num} é {reverso_numero(num)}.")

10. Jogo de Craps (Dados)

Faça um programa que implemente o Jogo de Craps usando o pacote random.
Regras: Na 1ª rolagem, tirar 7 ou 11 = Ganhou (Natural). Tirar 2, 3 ou 12 = Perdeu (Craps). Se tirar 4, 5, 6, 8, 9 ou 10, vira seu "Ponto". Continue rolando: se tirar o Ponto = Ganhou. Se tirar 7 antes = Perdeu.

import random

def rolar_dados():
    # Rola dois dados separadamente
    dado1 = random.randint(1, 6)
    dado2 = random.randint(1, 6)
    return dado1 + dado2

ponto = 0
jogada = 1

print("🎲 Bem-vindo ao Cassino - Jogo de Craps! 🎲")

while True:
    input(f"\n[Enter] para rolar os dados (Jogada {jogada})...")
    soma = rolar_dados()
    print(f"Você rolou: {soma}")
    
    if jogada == 1:
        if soma in [7, 11]:
            print("Natural! Você GANHOU! 🎉")
            break
        elif soma in [2, 3, 12]:
            print("Craps! Você PERDEU! 💀")
            break
        else:
            ponto = soma
            print(f"Seu Ponto é {ponto}.")
            print(f"Objetivo: Rolar {ponto} novamente antes de rolar um 7.")
    else:
        if soma == ponto:
            print(f"Você rolou o seu Ponto ({ponto})! Você GANHOU! 🎉")
            break
        elif soma == 7:
            print("Você rolou um 7 antes do seu Ponto! Você PERDEU! 💀")

11. Data por Extenso

Construa uma função que receba uma string de data no formato DD/MM/AAAA e devolva uma string no formato D de mês-por-extenso de AAAA. Retorne "Inválido" em caso de erro.

def data_por_extenso(data_str):
    meses = [
        "janeiro", "fevereiro", "março", "abril", "maio", "junho",
        "julho", "agosto", "setembro", "outubro", "novembro", "dezembro"
    ]
    
    # Tenta fatiar a data
    partes = data_str.split('/')
    if len(partes) != 3:
        return "Formato de data inválido."
        
    dia = int(partes[0])
    mes = int(partes[1])
    ano = int(partes[2])
    
    if 1 <= mes <= 12:
        nome_mes = meses[mes - 1] # Índice começa em zero
        return f"{dia} de {nome_mes} de {ano}"
    else:
        return "Mês inválido."

data = input("Digite a data (DD/MM/AAAA): ")
print(data_por_extenso(data))

12. Embaralhar Palavra

Construa uma função que receba uma string como parâmetro e devolva outra string com os caracteres totalmente embaralhados (use random.shuffle).

import random

def embaralhar_texto(palavra):
    # A string não tem "shuffle", precisamos converter pra lista primeiro
    lista_chars = list(palavra.lower())
    
    # Embaralha a lista in-place (direto na memória)
    random.shuffle(lista_chars)
    
    # Junta as letras de novo em uma string e converte para maiúsculo
    palavra_embaralhada = "".join(lista_chars).upper()
    
    return palavra_embaralhada

texto = input("Digite uma palavra: ")
print(f"Embaralhado: {embaralhar_texto(texto)}")

13. Desenha Moldura

Construa uma função que desenhe um retângulo usando os caracteres +, - e |. A função recebe linhas e colunas. Dentro da função, limite os valores mínimo (1) e máximo (20) caso o usuário extrapole.

def desenhar_moldura(linhas, colunas):
    # max/min garantem que o valor não fuja de 1 a 20
    linhas = max(1, min(20, linhas))
    colunas = max(1, min(20, colunas))
    
    # Construção do topo e da base
    if colunas > 1:
        topo_base = "+" + "-" * (colunas - 2) + "+"
    else:
        topo_base = "+"
        
    # Construção das paredes do meio
    if colunas > 1:
        meio = "|" + " " * (colunas - 2) + "|"
    else:
        meio = "|"
        
    # Desenhando
    print(topo_base)
    for _ in range(linhas - 2):
        print(meio)
    if linhas > 1:
        print(topo_base)

l = int(input("Quantidade de linhas (1-20): "))
c = int(input("Quantidade de colunas (1-20): "))
desenhar_moldura(l, c)

14. Matriz: Quadrado Mágico (3x3)

Elabore uma função que identifica e mostra na tela todos os "Quadrados Mágicos" de tamanho 3x3. Um quadrado mágico possui números de 1 a 9 onde a soma de qualquer linha, coluna ou diagonal sempre resulta em 15.

import itertools

def verificar_magico(matriz_plana):
    # A matriz será uma tupla de 9 índices. Ex: [0][1][2] é a 1ª linha
    
    # Linhas
    l1 = sum(matriz_plana[0:3])
    l2 = sum(matriz_plana[3:6])
    l3 = sum(matriz_plana[6:9])
    
    # Colunas
    c1 = matriz_plana[0] + matriz_plana[3] + matriz_plana[6]
    c2 = matriz_plana[1] + matriz_plana[4] + matriz_plana[7]
    c3 = matriz_plana[2] + matriz_plana[5] + matriz_plana[8]
    
    # Diagonais
    d1 = matriz_plana[0] + matriz_plana[4] + matriz_plana[8]
    d2 = matriz_plana[2] + matriz_plana[4] + matriz_plana[6]
    
    # Retorna True se TODOS somarem 15
    return l1 == l2 == l3 == c1 == c2 == c3 == d1 == d2 == 15

def imprimir_quadrados_magicos():
    # itertools cria todas as permutações possíveis com os números de 1 a 9!
    # Tem muita magia por baixo dos panos no Python...
    combinacoes = itertools.permutations(range(1, 10))
    
    contador = 0
    for p in combinacoes:
        if verificar_magico(p):
            contador += 1
            print(f"\nQuadrado Mágico #{contador}:")
            print(f" {p[0]} | {p[1]} | {p[2]} ")
            print(f" {p[3]} | {p[4]} | {p[5]} ")
            print(f" {p[6]} | {p[7]} | {p[8]} ")

print("Calculando todos os quadrados mágicos 3x3...")
imprimir_quadrados_magicos()
