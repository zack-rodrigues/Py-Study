📁 Exercícios com Arquivos

Aprenda a manipular o sistema de arquivos utilizando Python! Pratique as rotinas de leitura (read), escrita (write) e formatação de relatórios a partir de dados em formato .txt.

1. Validador de Endereços IP

Faça um programa que leia um arquivo texto contendo uma lista de endereços IP e gere um outro arquivo, contendo um relatório dos endereços IP classificados como válidos e inválidos (regras de IP: 4 blocos separados por pontos, variando de 0 a 255).

📅 Arquivo de entrada: ips.txt
200.135.80.9
192.168.1.1
8.35.67.74
257.32.4.5
85.345.1.2
1.2.3.4
9.8.234.5
192.168.0.256
📄 Arquivo de saída: relatorio_ips.txt
[Endereços válidos:]
200.135.80.9
192.168.1.1
8.35.67.74
1.2.3.4

[Endereços inválidos:]
257.32.4.5
85.345.1.2
9.8.234.5
192.168.0.256
# Função auxiliar para validar as regras do IPv4
def validar_ip(ip):
    partes = ip.split('.')
    # Um IP deve ter exatamente 4 partes
    if len(partes) != 4:
        return False
    # Cada parte deve ser número e estar entre 0 e 255
    for parte in partes:
        if not parte.isdigit() or int(parte) < 0 or int(parte) > 255:
            return False
    return True

# -------------------------------------------------------------
# Dica de Estudo: Bloco gerador do arquivo de entrada
# -------------------------------------------------------------
with open("ips.txt", "w") as f:
    f.write("200.135.80.9\n192.168.1.1\n8.35.67.74\n257.32.4.5\n85.345.1.2\n1.2.3.4\n9.8.234.5\n192.168.0.256\n")
# -------------------------------------------------------------

validos = []
invalidos = []

# Lendo o arquivo original
with open("ips.txt", "r") as arquivo:
    for linha in arquivo:
        ip = linha.strip()  # Remove espaços em branco e quebras de linha
        if validar_ip(ip):
            validos.append(ip)
        else:
            invalidos.append(ip)

# Escrevendo no novo arquivo de relatório
with open("relatorio_ips.txt", "w") as relatorio:
    relatorio.write("[Endereços válidos:]\n")
    for ip in validos:
        relatorio.write(f"{ip}\n")
    
    relatorio.write("\n[Endereços inválidos:]\n")
    for ip in invalidos:
        relatorio.write(f"{ip}\n")

print("Sucesso! Relatório 'relatorio_ips.txt' gerado no diretório atual.")

2. Relatório de Espaço em Disco por Usuário

A ACME Inc. está com problemas de espaço em disco no servidor. O administrador possui um arquivo com os nomes dos usuários e o espaço consumido (em bytes). Você deve ler este arquivo, converter de bytes para MB, e gerar um relatório indicando:

  • Espaço utilizado em Megabytes
  • Porcentagem de uso sobre o espaço total
  • Espaço total e espaço médio ocupado pela equipe
📅 Arquivo de entrada: usuarios.txt
alexandre       456123789
anderson        1245698456
antonio         123456456
carlos          91257581
cesar           987458
rosemary        789456125
📄 Arquivo de saída: relatorio.txt
ACME Inc.               Uso do espaço em disco pelos usuários
--------------------------------------------------------------
Nr.  Usuário        Espaço utilizado     % do uso
1    alexandre      434,99 MB            16,85%
2    anderson      1187,99 MB            46,02%
3    antonio        117,73 MB             4,56%
4    carlos          87,03 MB             3,37%
5    cesar            0,94 MB             0,04%
6    rosemary       752,88 MB            29,16%

Espaço total ocupado: 2581,57 MB
Espaço médio ocupado: 430,26 MB
# Função auxiliar: Transforma Bytes em MegaBytes
def bytes_para_mb(bytes_size):
    return bytes_size / (1024 * 1024)

# -------------------------------------------------------------
# Dica de Estudo: Bloco gerador do arquivo de entrada
# -------------------------------------------------------------
with open("usuarios.txt", "w") as f:
    f.write("alexandre       456123789\nanderson        1245698456\nantonio         123456456\ncarlos          91257581\ncesar           987458\nrosemary        789456125\n")
# -------------------------------------------------------------

usuarios = []
espacos = []
total_espaco_bytes = 0

# Lendo o arquivo de entrada
with open("usuarios.txt", "r") as arquivo:
    for linha in arquivo:
        # split() separa a linha por espaços (mesmo se houver múltiplos)
        partes = linha.split()
        if len(partes) == 2:
            nome = partes[0]
            espaco_bytes = int(partes[1])
            
            usuarios.append(nome)
            espacos.append(espaco_bytes)
            total_espaco_bytes += espaco_bytes

total_mb = bytes_para_mb(total_espaco_bytes)

# Escrevendo o arquivo de saída formatado
with open("relatorio.txt", "w") as relatorio:
    relatorio.write("ACME Inc.               Uso do espaço em disco pelos usuários\n")
    relatorio.write("-" * 65 + "\n")
    relatorio.write(f"{'Nr.':<4} {'Usuário':<14} {'Espaço utilizado':<20} {'% do uso'}\n")
    
    for i in range(len(usuarios)):
        espaco_mb = bytes_para_mb(espacos[i])
        percentual = (espacos[i] / total_espaco_bytes) * 100
        
        # Formatando as colunas alinhadas
        relatorio.write(f"{i+1:<4} {usuarios[i]:<14} {espaco_mb:>7.2f} MB {percentual:>16.2f}%\n")
    
    media_mb = total_mb / len(usuarios) if usuarios else 0
    relatorio.write("\n")
    relatorio.write(f"Espaço total ocupado: {total_mb:.2f} MB\n")
    relatorio.write(f"Espaço médio ocupado: {media_mb:.2f} MB\n")

print("Sucesso! Relatório gerencial 'relatorio.txt' criado.")
