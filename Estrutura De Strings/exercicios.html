8. Verificador de Palíndromo

Um palíndromo é uma sequência de caracteres cuja leitura é idêntica da direita para esquerda ou vice-versa (ignorando espaços e pontuação). Faça um programa que diga se o texto é um palíndromo.

Exemplo de palíndromos: SUBI NO ONIBUS, ANOTARAM A DATA DA MARATONA
texto = input("Digite a palavra/frase: ").upper()

# Limpando o texto (removendo espaços e mantendo só letras/números)
texto_limpo = "".join(caractere for caractere in texto if caractere.isalnum())

# Invertendo a string limpa
texto_invertido = texto_limpo[::-1]

if texto_limpo == texto_invertido:
    print("É um palíndromo!")
else:
    print("Não é um palíndromo.")

9. Verificação de CPF

Desenvolva um programa que solicite a digitação de um CPF no formato xxx.xxx.xxx-xx e valide se os dígitos verificadores (os dois últimos números) estão matematicamente corretos.

def validar_cpf(cpf):
    # Remove pontuações
    cpf_limpo = cpf.replace(".", "").replace("-", "")
    
    # Verifica tamanho ou se todos os números são iguais (ex: 111.111.111-11)
    if len(cpf_limpo) != 11 or cpf_limpo == cpf_limpo[0] * 11:
        return False

    # Calculando o primeiro dígito verificador
    soma = sum(int(cpf_limpo[i]) * (10 - i) for i in range(9))
    digito1 = (soma * 10 % 11) % 10

    # Calculando o segundo dígito verificador
    soma = sum(int(cpf_limpo[i]) * (11 - i) for i in range(10))
    digito2 = (soma * 10 % 11) % 10

    # Verifica se os dígitos batem
    return str(digito1) == cpf_limpo[9] and str(digito2) == cpf_limpo[10]

cpf_usuario = input("Digite o CPF (xxx.xxx.xxx-xx): ")

if validar_cpf(cpf_usuario):
    print("CPF Válido!")
else:
    print("CPF Inválido!")

11. Jogo da Forca

Desenvolva um jogo da forca. O programa escolhe uma palavra aleatória (pode ser de uma lista interna ou arquivo .txt). O jogador pode errar 6 vezes antes de ser enforcado.

import random

# Dica: Você pode usar `open("palavras.txt", "r")` para ler de um arquivo real
lista_palavras = ["PYTHON", "PROGRAMACAO", "COMPUTADOR", "ALGORITMO", "VARIAVEL"]
palavra_secreta = random.choice(lista_palavras)

letras_acertadas = ["_" for _ in palavra_secreta]
erros = 0
max_erros = 6

print("Bem-vindo ao Jogo da Forca!")
print(" ".join(letras_acertadas))

while erros < max_erros and "_" in letras_acertadas:
    chute = input("\nDigite uma letra: ").upper()

    if chute in palavra_secreta:
        for i, letra in enumerate(palavra_secreta):
            if letra == chute:
                letras_acertadas[i] = chute
        print("A palavra é:", " ".join(letras_acertadas))
    else:
        erros += 1
        print(f"-> Você errou pela {erros}ª vez. Tente de novo!")

if "_" not in letras_acertadas:
    print("\n🎉 Parabéns! Você ganhou!")
else:
    print(f"\n💀 Game Over! A palavra era: {palavra_secreta}")

12. Valida e Corrige Número de Telefone

Faça um programa que leia um número de telefone e, caso ele contenha somente 7 dígitos, acrescente o '3' na frente (antiga regra da telefonia). Considere números com ou sem hífen.

Telefone: 461-0133 Telefone possui 7 dígitos. Vou acrescentar o dígito três na frente. Telefone corrigido sem formatação: 34610133 Telefone corrigido com formatação: 3461-0133
telefone = input("Telefone: ")
tel_limpo = telefone.replace("-", "")

if len(tel_limpo) == 7:
    print("Telefone possui 7 dígitos. Vou acrescentar o dígito três na frente.")
    tel_corrigido = "3" + tel_limpo
    tel_formatado = f"{tel_corrigido[:4]}-{tel_corrigido[4:]}"
    
    print(f"Telefone corrigido sem formatação: {tel_corrigido}")
    print(f"Telefone corrigido com formatação: {tel_formatado}")
elif len(tel_limpo) == 8:
    print("Telefone já possui 8 dígitos e está correto.")
else:
    print("Número inválido.")

13. Jogo da Palavra Embaralhada

O usuário deve adivinhar uma palavra que será mostrada com as letras embaralhadas. Ele terá seis tentativas. Ao final, informe se ele ganhou ou perdeu.

import random

# Dica: Substitua por leitura de arquivo txt se desejar
banco_palavras = ["desenvolvedor", "tecnologia", "sistema", "internet"]
palavra = random.choice(banco_palavras).upper()

# Embaralha a string
embaralhada = "".join(random.sample(palavra, len(palavra)))

print(f"Adivinhe a palavra: {embaralhada}")

tentativas = 6
venceu = False

for i in range(tentativas):
    chute = input(f"\nTentativa {i+1}/6 - Seu palpite: ").upper()
    if chute == palavra:
        venceu = True
        break
    else:
        print("Palavra incorreta.")

if venceu:
    print(f"🎉 Parabéns, você acertou! A palavra é {palavra}.")
else:
    print(f"💀 Suas tentativas acabaram! A palavra correta era: {palavra}")

14. Leet Speak Generator

O "Leet" (ou 1337) troca letras normais por números ou símbolos parecidos. Faça um programa que receba um texto e o converta para a grafia hacker leet speak.

texto = input("Digite um texto: ").upper()

# Dicionário de tradução básica do Leet Speak
leet_dict = {
    'A': '4',
    'E': '3',
    'I': '1',
    'O': '0',
    'S': '5',
    'T': '7'
}

texto_leet = ""

for letra in texto:
    # Se a letra existir no dicionário, substitui. Se não, mantém a original.
    texto_leet += leet_dict.get(letra, letra)

print(f"Texto em Leet Speak: {texto_leet}")
